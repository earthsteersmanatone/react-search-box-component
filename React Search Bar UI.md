## 🛠 Feature Breakdown

### Feature 1 — Debounced Hook
Create a custom `useDebounce` hook to pause API calls.

### Feature 2 — Keyboard Nav
Navigate search results using Up, Down, and Enter keys.

### Feature 3 — Fuzzy Matching
Find results even with typos using a lightweight algorithm.

### Feature 4 — Loading States
Show spinners and handle empty states gracefully.

### Feature 5 — Highlighting
Automatically highlight the matched text.

### Feature 6 — TypeScript
Fully typed props and generic data support.

## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Search lags** | Increase debounce |
| **No results** | Check fuzzy threshold |
| **Focus lost** | Use `onMouseDown` |
| **A11y fails** | Add `aria-expanded` |
| **Test fails** | Wrap in `act()` |
| **Slow async** | Add AbortController |
